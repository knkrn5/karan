## Overview

This project is a web application built with a modern tech stack, including React for the frontend and Node.js for the backend. It leverages Contentful for content management and integrates with various APIs for extended functionality.

## Features

- User authentication and registration
- Blog post management with SEO meta tags
- Chatbot integration using OpenAI's API
- Responsive design with TailwindCSS
- Rich text rendering with Contentful

## Tech Stack

- **Frontend:** React, TypeScript, TailwindCSS
- **Backend:** Node.js, Express, MongoDB
- **Content Management:** Contentful
- **API Integration:** OpenAI
- **State Management:** Zustand
- **Routing:** React Router
