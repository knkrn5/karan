# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it to us via email at [mail@karan.email](mailto:mail@karan.email). We'll do our best to respond quickly and fix the issue.

## Supported Versions

All the version of this project is supported with security updates.

## Disclosure Policy

We disclose all security vulnerabilities to the public after a fix is available.

## Security Best Practices

This project follows best practices to ensure the secure development, deployment, and maintenance of the project. We:

- Follow the principle of least privilege when setting up user roles and access control.
- Keep software up to date with the latest security patches.
- Use secure protocols for communication (e.g. HTTPS).
- Validate and sanitize user input.
- Hash and salt passwords securely.
- Use secure random number generators.
- Keep sensitive data (e.g. encryption keys) confidential.
